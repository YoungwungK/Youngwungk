<h2>Projects</h2>

<h3><a href="REPO_URL_HERE">본사–지사 이중화 네트워크 및 보안 통신망 구축</a></h3>

<p>게이트웨이 · 링크 · 경로 · WAN 4개 계층의 단일 장애점(SPOF)을 각각 다른 기술로 제거하고, 12개 시나리오에 장애를 직접 주입해 검증했습니다. 검증하지 못한 항목(장애 복구 시간 미측정, 시뮬레이터의 IPsec 협상 제약)은 문서에 명시했습니다.</p>

<p>
  <code>HSRP + track</code>
  <code>LACP EtherChannel</code>
  <code>EIGRP 상호 재분배</code>
  <code>GRE over IPsec</code>
  <code>NAT / ACL</code>
</p>

<p>→ <b>담당:</b> 토폴로지 설계 · 기술 선정 · 검증 시나리오 작성 (3인 팀, 구현 공동) → 초기 설계에서 코어 스위치 간 연결이 단일 트렁크로 남아 SPOF가 된다는 점을 발견하고, Port-channel 이중화로 개선했습니다.</p>
